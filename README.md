# ✨ Comment & Emoji-to-Content Assistant

## About
I am Hina Arshad, a Computer Science graduate interested in **Python, AI, ML and Generative AI**.

## Project Idea
This project is an AI content assistant that converts a **topic, comment, or emojis** into a ready-to-post social media post.

## Features
- Topic → Content
- Comment → Content
- Emoji → Content
- Facebook, Instagram, LinkedIn, X/Twitter
- English, Urdu, Roman Urdu
- Different tones and content types
- Hashtags and CTA

## Technologies
- **Python**
- **Streamlit**
- **Google Gemini API**

## Project Setup

### Step 1: Create Folder
Create a project folder and open it in VS Code.

### Step 2: Install Libraries
Create `requirements.txt`:

```text
streamlit
google-genai

Install:

pip install -r requirements.txt
Step 3: Create Gemini API Key

Create a Gemini API key and add it to Streamlit Secrets.

Step 4: Create App

Create app.py and write the Python + Streamlit code.

Step 5: Run Locally
streamlit run app.py

Test the application in the browser.

Step 6: Upload to GitHub

Create a GitHub repository and upload:

app.py
requirements.txt
README.md
.gitignore

Never upload your API key.

Step 7: Deploy

Connect the GitHub repository with Streamlit Community Cloud.

Add:

GEMINI_API_KEY = "your_api_key"

to Streamlit Secrets and deploy the app.

Workflow

User Input → Streamlit → Gemini AI → Generated Content → Download
